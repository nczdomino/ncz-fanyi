哈喽中文 / Halou Zhongwen — Icon Pack

Nội dung:
- app-icons/: icon chính và 8 biến thể biểu tượng (PNG).
- favicons/: biểu tượng tròn/vuông có thể dùng làm favicon hoặc shortcut web.
- ui-icons/: icon minh hoạ cho các nút giao diện.
- extras/: biểu tượng trang trí.
- icon-sheet-reference.png: ảnh tổng hợp gốc để tham khảo.

Lưu ý:
- Các file được cắt từ ảnh concept tổng hợp, nên một vài icon có thể còn viền/nền trắng nhẹ do ảnh gốc.
- Icon trong pack là PNG RGB, không phải tất cả đều có nền trong suốt.
- Favicon đề xuất: favicon-square-h.png hoặc favicon-square-hanzi.png; dùng bản 32×32 khi triển khai bằng cách resize.
- App icon chính: app-icons/halou-zhongwen-main.png (1024×1024).
